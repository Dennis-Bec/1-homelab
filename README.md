
# Automated Linux Homelab

## Project Overview

This project demonstrates the setup, administration and
automation of a Linux server environment.

The infrastructure runs on dedicated hardware using
Ubuntu Server as its operating system.

The goal is to build a maintainable and well-documented
environment using modern infrastructure tools.

## Technologies

- Ubuntu Server
- Docker
- Docker Compose
- Bash
- Git and GitHub
- Ansible
- Grafana
- Uptime Kuma

## Project Goals

- Automate Linux server administration
- Manage containerized applications
- Implement configuration management with Ansible
- Automate tasks using Bash
- Monitor services and system availability
- Document infrastructure and configuration

## Repository Structure

| Directory      | Description              |
|----------------|--------------------------|
| ansible/       | Configuration management |
| docker/        | Container configurations |
| scripts/       | Automation scripts       |
| documentation/ | Technical documentation  |

## Infrastructure

- Physical server 
- Ubuntu Server
- Docker-based services
- Remote administration via SSH
